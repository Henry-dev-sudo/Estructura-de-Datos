# Cuadernillo 3

Este cuadernillo continúa el trabajo con estructuras de datos y programación en Python. Se practican funciones, estructuras de control, pilas y colas mediante ejemplos independientes y pequeños sistemas.

> Este documento se irá actualizando conforme se incorporen nuevas clases y tareas al cuadernillo 3.

## Estructura de carpetas

### Clases

Los ejemplos se organizan por número de clase:

- `clase15`: funciones.
- `clase 16`: pilas y funciones para trabajar con pilas.
- `clase 17`: estructuras condicionales y ciclos.
- `clase18`: colas y simulación de atención en un banco.

### Tareas

La carpeta `Tareas` está destinada a los ejercicios que se agreguen durante el desarrollo del cuadernillo.

## Temas trabajados

### Clase 15: funciones

- [funciones.py](Clases/clase15/funciones.py): definición de funciones, parámetros, valores de retorno y uso de funciones para saludar o sumar.

### Clase 16: pilas

- [pilas.py](Clases/clase%2016/pilas.py): representación de una pila usando una lista y la operación `append()`.
- [funcionesPila.py](Clases/clase%2016/funcionesPila.py): creación de funciones `push` y `pop` para agregar y retirar elementos de una pila.
- [ejercicio.py](Clases/clase%2016/ejercicio.py): ejercicio de aceleración y desaceleración de un vehículo mediante funciones.

### Clase 17: estructuras de control

- [if.py](Clases/clase%2017/if.py): toma de decisiones con `if`.
- [Elif.py](Clases/clase%2017/Elif.py): uso de varias condiciones con `if` y `elif`.
- [for.py](Clases/clase%2017/for.py): repetición de instrucciones con el ciclo `for`.
- [while.py](Clases/clase%2017/while.py): repetición controlada con el ciclo `while`.

### Clase 18: colas

- [cola.py](Clases/clase18/cola.py): estructura básica de una cola.
- [Operaciones-de-cola.py](Clases/clase18/Operaciones-de-cola.py): operaciones para agregar y retirar elementos de una cola.
- [sistema-de-un-banco.py](Clases/clase18/sistema-de-un-banco.py): aplicación del concepto FIFO en un sistema de atención bancaria.

## Temas que se continuarán agregando

- Nuevas clases y ejercicios.
- Aplicaciones de pilas y colas.
- Estructuras de control relacionadas con los nuevos problemas.
- Tareas prácticas incorporadas en la carpeta `Tareas`.
