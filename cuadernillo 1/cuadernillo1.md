# Cuadernillo 1

Este cuadernillo reúne los primeros ejercicios de Python. El trabajo comienza con la impresión de mensajes y el uso de caracteres especiales, y avanza hacia variables, tipos de datos, entradas del usuario y operaciones matemáticas.

## Estructura de carpetas

### Clases

Los archivos de clase están organizados por los temas vistos:

- `clase-1`: primer programa y salida por pantalla.
- `clae-2`: impresión, variables y tipos de datos básicos.
- `clase-3`: entradas de datos, variables y operaciones con números.

### Tarea

La carpeta `Tarea` contiene ejercicios para practicar la función `print()`, las cadenas de texto, los caracteres de escape y las listas anidadas.

## Temas trabajados

### Clase 1: salida por pantalla

- [Hola_Mundo.py](clases/clase-1/Hola_Mundo.py): programa inicial para mostrar un mensaje en Python.

### Clase 2: impresión, variables y tipos de datos

- [clase2.py](clases/clae-2/clase2.py): declaración de variables y conversión de valores.
- [print.py](clases/clae-2/print.py): impresión de cadenas, comillas, saltos de línea y longitud de texto.
- [temp.py](clases/clae-2/temp.py): ejemplos de números enteros, decimales y valores booleanos.
- [tiposDeDatos.py](clases/clae-2/tiposDeDatos.py): tipos numéricos y booleanos, además de consulta de tipos.

### Clase 3: entrada, variables y operaciones

- [intputs.py](clases/clase-3/intputs.py): lectura del nombre y apellido mediante `input()`.
- [variables.py](clases/clase-3/variables.py): almacenamiento de datos en variables y conversión de números a texto.
- [operaciones(numeros).py](clases/clase-3/operaciones%28numeros%29.py): suma, resta, multiplicación, división, potencia y comprobación de números pares.

### Tarea: ejercicios básicos

- [ejercicios.py](Tarea/ejercicios.py): impresión de una estrofa, creación de una matriz de ceros de 3x3 y uso de caracteres de escape para mostrar barras.

## Resumen

El cuadernillo 1 establece las bases para programar en Python: mostrar información, recibir datos, guardar valores, reconocer tipos de datos y realizar operaciones sencillas.
